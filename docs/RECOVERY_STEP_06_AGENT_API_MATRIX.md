# RECOVERY STEP 6 — TEAM ASSIGNMENT & AGENT OPERATIONS API MATRIX
**CampaignOps AI — REST Endpoints, Allowed Roles, Validation & Audit Logs**

| Method | Endpoint | Allowed Roles | Request Body / Parameters | Success Code & Response | Audit Event Action | Description & Scope Enforcement |
|---|---|---|---|---|---|---|
| `GET` | `/api/v1/users` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN` | Query: `campaignId` (req for admin) | `200 OK`<br>`{ data: User[] }` | None (Read) | Lists team members belonging to requested campaign with assignment scope and role. |
| `POST` | `/api/v1/users` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN` | Body: `{ email, displayName, role, phone, password, campaignId }` | `201 Created`<br>`{ data: User, meta: { message } }` | `AGENT_ADDED_TO_CAMPAIGN` | Provisions user, hashes password with `scrypt`, and establishes active `CampaignMembership`. |
| `GET` | `/api/v1/tasks` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` | Query: `campaignId`, `userId` | `200 OK`<br>`{ data: Assignment[] }` | None (Read) | Retrieves tasks. For `POLITICAL_AGENT`, automatically filters to only tasks where `userId = principal.userId`. |
| `POST` | `/api/v1/tasks` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN` | Body: `{ campaignId, userId, scopeType, scopeTarget, taskType, notes, boothId, wardId }` | `201 Created`<br>`{ data: Assignment }` | `ASSIGNMENT_CREATED` | Creates field assignment, prevents duplicate active assignments (409 Conflict), and links booth scope to membership. |
| `GET` | `/api/v1/tasks/[id]` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (assigned only) | Path: `id` | `200 OK`<br>`{ data: Assignment }` | None (Read) | Retrieves task details. Agent restricted to own task. |
| `PATCH` | `/api/v1/tasks/[id]` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (assigned only) | Body: `{ status, notes, dueAt, userId, scopeTarget }` | `200 OK`<br>`{ data: Assignment }` | `ASSIGNMENT_UPDATED` / `ASSIGNMENT_CANCELLED` | Updates task status or reassignment. Agents forbidden from reassigning or expanding scope. |
| `GET` | `/api/v1/voters` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (scoped to assigned booth) | Query: `q`, `campaignId`, `booth`, `ward`, `limit`, `page` | `200 OK`<br>`{ data: Voter[], meta: { pagination } }` | None (Read) | Searches electors. For `POLITICAL_AGENT`, strictly applies `WHERE boothId IN (assignedBooths)`. |
| `GET` | `/api/v1/voters/[id]` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (scoped to assigned booth) | Path: `id` | `200 OK`<br>`{ data: Voter }` | None (Read) | Fetches single voter details. Rejects out-of-scope booth with 403 Forbidden. |
| `GET` | `/api/v1/households/[hid]` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (scoped to assigned booth) | Path: `hid` | `200 OK`<br>`{ data: Household }` | None (Read) | Opens household dossier. Rejects out-of-scope booth with 403 Forbidden. |
| `POST` | `/api/v1/households/[hid]` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (scoped to assigned booth) | Body: `{ status, notes, voterId }` | `201 Created`<br>`{ data: Interaction }` | `FIELD_VISIT_RECORDED` | Appends real door-to-door interaction history, updates operational visit status, and logs audit event. |
| `PATCH` | `/api/v1/households/[hid]` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (scoped to assigned booth) | Body: `{ address, houseNumber, primaryContactName, status }` | `200 OK`<br>`{ data: Household }` | `HOUSEHOLD_ADDRESS_CORRECTED` | Updates household details with optimistic locking and audit trail. |
| `POST` | `/api/v1/issues` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` | Body: `{ campaignId, boothId, householdId, title, category, priority, description }` | `201 Created`<br>`{ data: Issue }` | `ISSUE_CREATED` | Reports operational discrepancy or follow-up from the field and records audit event. |
| `GET` | `/api/v1/issues` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` | Query: `campaignId`, `category`, `status` | `200 OK`<br>`{ data: Issue[] }` | None (Read) | Lists campaign operational issues and follow-ups. |
