# RECOVERY STEP 5 — HOUSEHOLD & FAMILY GROUPING API MATRIX
**CampaignOps AI — REST Endpoints, Roles & Audit Logging**

| Method | Endpoint | Allowed Roles | Request Body / Query Params | Success Code & Response | Audit Event Action | Description |
|---|---|---|---|---|---|---|
| `GET` | `/api/v1/households` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (Scoped to assigned booth) | Query: `campaignId` (req), `boothId`, `status` (`ALL`, `CONFIRMED`, `NEEDS_REVIEW`, `SUGGESTED`), `q`, `page`, `limit` | `200 OK`<br>`{ data: Household[], meta: { total, page, limit, totalPages, confirmedCount, needsReviewCount, suggestedCount } }` | None (Read) | Lists households with member summary, evidence signals, and filtering. |
| `GET` | `/api/v1/households/[hid]` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (Scoped to assigned booth) | Path: `hid` (Household ID or Code) | `200 OK`<br>`{ data: Household (with members, booth, interactions, issues) }` | None (Read) | Retrieves full household profile and dossier. |
| `POST` | `/api/v1/households/grouping/run` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN` | Body: `{ campaignId: string, boothId?: string, forceRegroupUnconfirmed?: boolean }` | `200 OK`<br>`{ data: { totalProcessedVoters, householdsCreated, householdsUpdated, preservedManualHouseholds } }` | `HOUSEHOLD_SUGGESTED` | Executes deterministic household grouping across published voters. |
| `POST` | `/api/v1/households/[hid]/confirm` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (Scoped to assigned booth) | Path: `hid` | `200 OK`<br>`{ data: Household, meta: { message: "Household confirmed successfully" } }` | `HOUSEHOLD_CONFIRMED` | Confirms household grouping and sets `isManuallyCorrected = true`. |
| `POST` | `/api/v1/households/[hid]/move-member` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (Scoped to assigned booth) | Body: `{ voterId: string, targetHouseholdId?: string, createNewHousehold?: boolean }` | `200 OK`<br>`{ data: { voter, sourceHousehold, targetHousehold } }` | `HOUSEHOLD_MEMBER_MOVED` | Reassigns a voter to another household or creates a new household. Creates `VoterFieldProvenance`. |
| `POST` | `/api/v1/households/[hid]/split` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (Scoped to assigned booth) | Body: `{ voterIds: string[], newHouseholdAddress?: string }` | `200 OK`<br>`{ data: { originHousehold, newHousehold } }` | `HOUSEHOLD_SPLIT` | Splits selected voters into a new household within the same polling booth. |
| `POST` | `/api/v1/households/[hid]/merge` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (Scoped to assigned booth) | Body: `{ targetHouseholdId: string }` | `200 OK`<br>`{ data: Household, meta: { message: "Households merged successfully" } }` | `HOUSEHOLD_MERGED` | Merges another household into this household. Both must be in the same polling booth. Deletes merged unit. |
| `PATCH` | `/api/v1/households/[hid]` | `SUPER_ADMIN`, `CAMPAIGN_ADMIN`, `POLITICAL_AGENT` (Scoped to assigned booth) | Body: `{ address?: string, houseNumber?: string, primaryContactName?: string, primaryContactId?: string }` | `200 OK`<br>`{ data: Household, meta: { message: "Household updated successfully" } }` | `HOUSEHOLD_ADDRESS_CORRECTED` | Updates operational address or primary contact for household. |
