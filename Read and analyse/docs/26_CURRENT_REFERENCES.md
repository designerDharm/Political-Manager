This documentation is an engineering plan, not legal advice. Before production deployment using electoral-roll or campaign-related personal data, obtain jurisdiction-specific legal review covering:
- lawful access/use of electoral roll data
- privacy notices and data processing
- retention/deletion
- political campaign rules
- polling-day/VIS workflows
- security incident obligations
